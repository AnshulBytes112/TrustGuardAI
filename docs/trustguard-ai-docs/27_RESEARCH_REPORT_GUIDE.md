# Research Report Guide

## Required Sections

1. Problem statement
2. Motivation
3. Literature survey
4. Base paper
5. Existing system
6. Limitations
7. Proposed TrustGuard system
8. Architecture
9. Dataset
10. Poisoning methodology
11. Model
12. Multi-layer representation method
13. Detection algorithms
14. Risk scoring
15. Explainability
16. Purification
17. Experimental setup
18. Results
19. Ablation study
20. Limitations
21. Future work
22. Conclusion

## Result Integrity

All tables and graphs must be generated from experiment artifacts.

Do not manually enter values.

## Claims

Separate:
- published-paper facts
- project implementation choices
- experimentally observed results
- future hypotheses
